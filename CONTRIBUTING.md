# Contributing to Air

Thanks for wanting to contribute! This document outlines the expected workflow.

- Issues: open issues for bugs or feature requests. Provide reproduction steps and logs when applicable.
- Branches: use `feat/`, `fix/`, or `chore/` prefixes.
- PRs: include tests, update `CHANGELOG.md` for notable changes, and link related issues.
- Code style: follow Rust idioms, run `cargo fmt` and `cargo clippy` before submitting.
- Reviews: maintainers will review for correctness, security, and compatibility.

Security

- If you discover a security issue, follow the repository's security policy to disclose privately before opening a public issue.

Licensing

- By contributing you agree that your contributions will be available under the repository license (CC0 by default). If you cannot contribute under CC0, contact the maintainers.
